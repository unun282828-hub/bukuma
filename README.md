# ブクマ帳

X（旧Twitter）のブックマークを「レシピ」「情報」「その他」に分けて、スマホで見るためのWebアプリです。

- HTML1ファイルだけで動きます（サーバー不要）
- ブックマークのデータは**このリポジトリには入っていません**。スマホで読み込んだデータは、そのスマホのブラウザの中（IndexedDB）にだけ保存されます
- 「⏰ あとで確認」の印、「🍳 今日作った」の記録、メモを付けられます
- メニューの「🧪 サンプルで試す」で、架空のデータで動きを試せます

## 使い方

1. iPhoneのSafariでこのページを開き、共有ボタンから「ホーム画面に追加」する
2. メニュー（⋯）→「📥 データを読み込む」で、ブクマ帳の形式のJSONファイルを選ぶ

## データの形

```json
{
  "items": [
    {
      "id": "1234567890",
      "url": "https://x.com/user/status/1234567890",
      "createdAt": "2026-11-20T19:02:00+09:00",
      "author": { "name": "表示名", "handle": "user" },
      "text": "ポストの本文",
      "media": [{ "url": "https://pbs.twimg.com/..." }],
      "category": "recipe | info | other",
      "later": false,
      "tags": ["鶏肉", "時短"],
      "summary": "一言の要約（情報向け）",
      "recipe": { "title": "料理名", "servings": "2人分", "ingredients": ["鶏むね肉 1枚"], "steps": ["…"] }
    }
  ]
}
```
